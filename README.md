# Pawsitive Pet Academy Website

## About

This project is a website for **Pawsitive Pet Academy**, a pet care education and animal training business. The website provides information about the academy and its courses. 

## Pages

* Home
* Six-Month Courses
* Six-Week Courses
* Course Details
* Calculate Fees
* Contact

## Technologies

* HTML5
* CSS3
* Visual Studio Code

## Features

* Navigation menu
* Course cards and images
* Hero/banner section
* Course information
* Fee calculation page
* Contact information
* Simple and user-friendly layout
